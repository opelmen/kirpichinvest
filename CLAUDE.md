# Навигация по коду

Для поиска и понимания кода сначала используй codebase-memory-mcp: `search_graph` (символы), `trace_path` (кто вызывает / что вызывает), `get_code_snippet` (исходник), `get_architecture` (обзор). Файлы целиком читай только при необходимости. Для строковых литералов используй `search_code` или grep.

# Общие правила проекта

Обязательно прочитай и соблюдай `AGENTS.md` в этой папке: там правила постоянного контекста, реестра задач, журнала действий и бэкапов для всех чатов проекта «Кирпичи». Начинай с `_project/00_План и журнал/CURRENT_STATE.md` и связанных документов. История чата не заменяет записи на диске.

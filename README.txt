Состав архива:
- index.html — главная страница с квизом
- privacy.html — политика обработки персональных данных
- consent.html — согласие на обработку персональных данных
- offer.html — пользовательское соглашение

Как разместить:
1. Загрузите все файлы в корень сайта на хостинге.
2. Убедитесь, что домен работает по HTTPS.
3. Перед запуском рекламы проверьте, что ссылки на Telegram/MAX открываются корректно.
4. Для юридической чистоты желательно дополнительно проверить тексты у профильного юриста по рекламе и 152-ФЗ.

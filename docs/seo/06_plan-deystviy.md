## Инструменты: что есть, что не подключилось, что поставить

### Что не подключилось в этой сессии и почему

Серверы плагинов, отмеченные в сессии как «не подключились», все с одной ошибкой: сеть контейнера отвечает 403 на соединение с их хостами. Это сетевая политика среды, а не отсутствие ключей.

| Плагин / сервер | Что даёт | Хост, который надо разрешить |
|---|---|---|
| jsonseo | Вордстат (частотность, сезонность, регионы), позиции в Яндексе и Google, прогноз Директа | хост MCP-сервера jsonseo (виден в настройках плагина) |
| seo-skills: se-ranking | Позиции, ссылки конкурентов, аудит | api.seranking.com или хост MCP |
| seocrawl-reports | Отчёты по обходу и AI-видимости | mcp.seocrawl.ai |
| serpzilla | Покупка ссылок и гостевых постов | хост MCP serpzilla |
| exa | Поиск по вебу для исследования | mcp.exa.ai |
| github plugin | дубль встроенного GitHub, не нужен | — |

Также закрыт прямой доступ к torggid.ru, tbankrot.ru и остальным сайтам из контейнера (curl и Playwright); работал только встроенный WebFetch, который сам соблюдает robots.txt и поэтому не открыл torgi-rossii, probankrot, geveya, lot-online.

**Как открыть (John):** сетевая политика среды отклонила эти хосты. У проекта нет своей облачной среды, он работает на встроенной без настроек. Нужно в [Project settings](#project-settings/environment) в меню «Cloud environment» выбрать «Add cloud environment», в «Network access» выбрать более широкий уровень или добавить хосты выше в «Allowed domains» (галочку «Allow package managers» оставить). Новые сессии после этого пойдут через эту среду. Инструкция: https://code.claude.com/docs/en/cloud-environments#network-access. Минимум, чтобы заработал Вордстат и позиции: хост jsonseo плюс torggid.ru и tbankrot.ru для живых проверок.

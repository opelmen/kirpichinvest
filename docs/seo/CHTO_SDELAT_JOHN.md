Открыть терминал в папке `D:\Кирпичи` (правый клик по папке → «Открыть в терминале» или PowerShell), вставить одну строку и нажать Enter:

```powershell
[Console]::OutputEncoding=[Text.Encoding]::UTF8; git fetch origin claude/seo-geo-research-rdazms; git show origin/claude/seo-geo-research-rdazms:docs/seo/razlozhit.ps1 | Out-File -Encoding utf8 "$env:TEMP\razlozhit.ps1"; powershell -ExecutionPolicy Bypass -File "$env:TEMP\razlozhit.ps1"
```

Что сделает скрипт, по шагам, с выводом на экран:
- скачает папку исследования из ветки в `_project\seo\2026-10-11\` (10 файлов, в том же месте, где лежит план от 03.10);

- сделает копию `ACTION_LOG.md` и `CURRENT_STATE.md` в `_project\backups\2026-10-11_seo\`;
- допишет запись в `ACTION_LOG.md` и раздел SEO в конец `CURRENT_STATE.md`.

Ничего не удаляет, рабочую ветку не меняет, в git ничего не коммитит. Если что-то пойдёт не так, скрипт остановится и напишет, на чём.

## 3. Bing Webmaster (15 минут)

ChatGPT и Perplexity ищут через Bing. Без этого шага они сайт почти не видят.

1. Зайти на https://www.bing.com/webmasters с любой учёткой Microsoft.
2. «Add a site» → `https://torggid.ru`. Самый быстрый путь: «Import from Google Search Console» (сайт в GSC уже есть), тогда код не нужен.
3. Если импорт не предложен: выбрать «Meta tag», скопировать значение `content="..."` и прислать мне. Я вставлю его в `_src/config.json` → `BING_VERIFICATION`, он попадёт в пачку.
4. После подтверждения: Sitemaps → добавить `https://torggid.ru/sitemap.xml`.

## 4. Яндекс Вебмастер, три проверки (10 минут)

https://webmaster.yandex.ru, сайт torggid.ru.

1. «Представление в поиске» → «Региональность»: регион должен быть «Россия» или не задан. Если стоит «Санкт-Петербург» (так было у старого домена), сменить на Россию: иначе страницы Казани и Новосибирска в своих регионах показываются хуже.
